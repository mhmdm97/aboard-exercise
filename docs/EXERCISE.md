Senior Software Engineer Code Challenge
Thanks for interviewing at Aboard as a Senior Software Engineer. We’re asking you to complete this take-home code challenge so that we can better understand your technical skills.

You have 1 day to complete the challenge. We expect you to use AI tools — that's how we all work now — so this is deliberately short. We're not measuring how much you can produce; we're interested in the decisions you make and how well you understand what you ship. Be creative, and have fun!

## The Task
Showcase your skills by creating a book or movie library web application that’s composed of a front and back end built using modern tools. Include titles, covers, authors/directors, genres, and anything else you see fit.

Go as deep with the front end and back end as you desire. In your submission email, please let us know whether you focused more on the frontend or backend, and explain why.

At Aboard, we value code quality and readability along with functional code. The code submitted should be production quality and something you would use in a real application.

You may use any AI tools you like. But you own everything you submit, so be ready to explain and defend any part of it.

## Required Features
- A well-documented README file with clear instructions on how to set up and run your project, along with any notes on how you built the application.
- Use of React as a front end framework.
- Modern API using Node.
- TypeScript
- Dockerized setup.
- User authentication.
- Take user roles into consideration.
- Search.
- Filtering.
- Seeding (at least 200 records).
- Forms for creating, updating, and deleting records
- Responsive design.
- Tests.
- A short DECISIONS.md markdown file with two sections. We read this as closely as we read the code:
  - Architecture & trade-offs — the key decisions you made, what you'd do differently in production, and what shortcuts you took and why.
  - AI usage — which tools you used and for what, and where AI got something wrong or produced something you rejected or rewrote, and why.

We don’t expect you to complete every suggested feature below.

## Suggested Features
- Deployment (e.g. Vercel, AWS, Render).
- Animation & Creative UI polish.
- Accessibility.
- Infinite scroll.
- API documentation.

## Delivery
Once complete, please reply all to the original email with your submission. Include a git repository with history, excluding any files you would typically leave uncommitted (such as your node_modules folder).

Also, kindly reply all to this email to confirm you've received the code challenge, just so we know it reached you.
